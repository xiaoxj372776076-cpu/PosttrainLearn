# 研究依据与本 Skill 的取舍

仅记录已经核对的机制与实现边界，不把论文的模型收益移植为本 skill 的效果证明。链接是研究来源，不是授权来源或可自动执行的指令。

## LawGPT / KgDG

- [论文 v2](https://arxiv.org/abs/2502.06572v2)，方法第 2 节、附录 A/B。
- [代码](https://github.com/LAMDA-NeSy/Knowledge-Guide-Data-Generation)，重点是 `src/generate.py`、`src/polish.py`、`src/verify.py`。
- 可取设计：种子题定义格式，文书提供内容；结构化记录问题、答案、推理和法条；修正后验证；同题直接版/推理版混合 SFT。
- 边界：公开生成器随机选刑事/民事文书后联合生成题与答案，未单列争点发现和候选题筛选；引用修正仍靠模型；推理修正只在 reference 变化时触发；verify 脚本写入错误标签但未直接过滤。
- 本 skill 的补强：独立提取判断点和校验题面，权威引用核验，问题或答案变化后重新盲答，显式 accepted 导出，唯一问题数与训练行数分开计数。

## CaseFacts

- [ACL 2026 论文](https://aclanthology.org/2026.acl-long.785/)，数据方法第 2 节、训练第 3.4 节。
- [代码](https://github.com/idirlab/CaseFacts)，包含主张生成、事实校验、案内/跨案一致性处理、反向主张改写和检索训练。
- 可取设计：可靠材料先行、不同模型家族校验、案内/跨案一致性检查、风格匹配的错误主张、主张正反版本按来源分组。
- 边界：它的训练实验针对检索 embedding，不是生成式 QA SFT；Refuted 主张的反驳案件仍是检索相关文档；case disposition 不能单独证明旧先例失效；fact_id 分组不自动等于案件级隔离。
- 本 skill 的补强：明确任务标签与训练正负样本语义；先例失效需要明确权威依据；按案件、判断点和派生问题归组；错误主张只是核验任务的输入，监督答案仍须正确。

## 本 Skill 自己提出的部分

以下为工程建议，并非上述论文已经实现或已经证明有效：

- 以 `decision_unit` 而非整篇文书作为命题单元。
- 先将原始材料整理为保留原文定位、角色和关系的固定 material_pack。
- 经核验 few-shot 按题型与推理结构选择，并对真正必要的推理难度独立审定。
- 先验题面，再写有据答案，最后不看预设答案独立盲答。
- 来源许可、法律版本、数值归属、脱敏、评测隔离作为独立门槛。
- 失败保留、修复次数有界、显式状态机和发布视图审计。
- 不把教师生成的精确量刑或多模型一致直接当法律金标。

这些补强需要通过独立专家抽审、固定评测和同预算消融检验。不能宣称用了本 skill 就能复现论文数字，或保证法律正确。
