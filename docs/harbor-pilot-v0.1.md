# Harbor 法律文件合成 Pilot 0.1

这是 Skill 1.1.0 的任务适配协议，不覆盖其历史快照。范围为一份公开、已脱敏判决书的封闭材料审计，不是法律意见，也不把不完整案件包装为庭前完整卷宗。

## 运行边界

- 只做 1 个原案任务；设计目标 D4，最后由 P3/P6 和真实盲答结果分别报告结构难度和经验难度。
- P0 复用案件整理底稿，确定性映射为 material_pack 1.0，保留 partial。仅选材料齐全的返还范围单元；未知证据原件、资金逐笔追踪和净利息矛盾仍显式保留。
- PLawBench 全部 280 条保持 protected，不传模型。三个 independent 假设规则示例仅示范逻辑结构；确定性检查不等于专家审核，也没有验证其难度真的达到 D4。
- 预算上限 12 次网关 API 提交（含预检、失败、修复及 3 次盲答），单请求最多 10,000 输出 token，总输入上限 160,000、总输出上限 100,000。价格未知，不声称费用为零。API 超限、输入超限或语义检查失败就停止当前阶段，不无限重试。
- 模型采用已有网关 gpt-6-astra；教师、题面审查和盲答使用独立上下文但同一家族，独立性有限。网关返回服务别名不证明固定权重版本。
- 每个阶段保存真实 prompt、响应、输入/输出 SHA-256、模型服务标识、usage、时间、失败和选择理由。

## Harbor 边界

任务采用 Harbor 0.25.0 / task schema 1.4 / Smol Linux VM。学生只读 `/app/input`，最终写入 `/app/output/audit.json`。测试和 oracle 只在独立阶段由 Harbor 注入；自定义代理只支持读白名单材料、提交 JSON，不执行模型生成的任意 shell。这是受限文件代理，不是通用 terminal agent。

每次盲答在真实 Harbor trial 中读取 VM 中的文件，调用模型，写回 VM，由 Harbor 执行隐藏 verifier。它不是将预先保存答案回放为模型 rollout。网页是研究者视图，允许查看答案和 verifier；学生 prompt 不读取研究者接口。

Oracle 必须全通过，nop 必须为零，还需错误金额、重复计款、版本混用、猜测未知事实和伪造来源等负控。VM 是隔离执行环境，不是恶意 root 级代理下的绝对防作弊系统；此 pilot 不采用任意命令工具，禁止尝试读取 `/tests`、`/solution`、`/logs/verifier`。

## 评分与 BoN

固定 verifier 在评测前冻结并存哈希。金额用 Decimal；核对金额角色、计入/排除、去重、关键来源、版本和未知状态。总分为独立检查组等权均值；全通过才算 strict success，部分分不可抵消核心错项。文本理由只检查非空及证据定位，不能证明法律语义正确；P6 另审法律依据和解释。

BoN N=3，三次相同题面、相同模型/预算、新上下文，不向后一答提供前一答、分数或错误。报告每次分数、首答、strict success 数和最大分。选最优使用隐藏 verifier，是 oracle best-of-N 上界，不是可上线的无金标候选选择器，也不是 pass@k 的无偏估计。只有一个题目，不能估计总体难度或模型法律能力。

本轮执行补记：第三个原始 trial 网关超时、无完成答案，Harbor记录reward=0但step存在异常，不能当法律错答。保留失败trial并仅补跑一次；报告3份完成答案及1次基础设施失败、共4个模型trial。该次API提交计入12次上限，未知用量与计费不填0。适配器0.1.1增加取消时子进程清理，不改变学生材料、提示词或评分标准。

任务元数据的 `difficulty = hard` 是冻结试跑时的 D4 设计目标，不是经验认证。P3-r2审定D3，最终发布报告按较保守的审定等级处理；本轮不导出任何“已批准高难度任务”。

## 发布门槛

Harbor 实验任务与正式训练发布分开。任一必需检查 unresolved/fail 就隔离；未知再分发/隐私范围、专家未审、benchmark 近重复未审和高难度缺乏支持均如实展示。训练导出不得为了展示完整流程虚填 pass；可以完整结束为 quarantine、训练行 0。

官方司法文件及法条的有限研究处理依据为《著作权法》第五条第一项，不能据此推断私人证据、个人信息和商业再分发均获许可。原始案件包的 permission_status 仍为 unresolved；本轮用途仅限本地、脱敏、已公开司法文件的研究加工。
